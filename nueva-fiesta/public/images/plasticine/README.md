# Plasticine (Craftwork Studio)

Licencia **Commercial** comprada por el usuario. Aquí van solo versiones optimizadas para la web
(recortadas, máx. 800 px, WebP). No subir los PNG/Blender/Figma originales al repo.

Nombres: `{pack}-{objeto}.webp` (packs: lifestyle, nature, shapes).
