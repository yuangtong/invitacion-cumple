## Lectura
- **Cumpleaños = globos inflados** (01, 02, 03, 06, 07, 11, 12, 13).
- **Club = cartel de fiesta** (04, 05): tipografía de puntos o grotesca apretada, horarios, lineup.
- La mezcla de los dos es la identidad de *Huamanga Club, Edición 0*: un cumpleaños que se cree club.
